# Unity 资源整理工具

中文 Unity 编辑器工具，提供移动合并、引用查询、资源清理、命名工具、场景同步和资源分析。

已在 Unity 2022.3.62f3 验证。仅运行于 Editor，无需第三方插件；Unity 6 尚未验证。

## 安装

1. 下载本仓库（Code → Download ZIP）。
2. 将 `Assets/ResourceOrganizer` 复制到 Unity 工程的 `Assets` 下。
3. 等待编译，打开 `Tools → 资源整理工具`。

更新时先关闭工具窗口，覆盖整个工具目录并保留工程中已有的 `.meta`，再重新打开。`Tests` 无需复制到日常工程。

## 使用

| 页签 | 操作 |
| --- | --- |
| 移动合并 | 选择「需要移动文件」与「目标文件」，生成预览，勾选后执行；同名目录合并，文件冲突按所选策略处理。 |
| 引用查询 | 添加资源或文件夹，选择全部场景或指定场景后扫描；已引用资源在 Project 窗口标红，可将未引用结果送入清理。 |
| 资源清理 | 载入查询结果，勾选后移入系统回收站；不重复全工程复核。手动添加、没有查询依据的范围仍需复核。 |
| 命名工具 | 拖入资源，查找依赖与引用；支持关系、类型和名称筛选。按下方流程预览并改名。 |
| 场景同步 | 扫描活动场景中的 Prefab 实例名称差异，勾选同步；支持 Undo，不自动保存场景。 |
| 资源分析 | 分析当前场景、指定场景或资源范围，查看类型、内存估算、缺失引用，并导出 CSV。 |

### 命名流程

1. 拖入资源并查找；列表显示文件图标、关系和状态，可筛选模型、材质、贴图等类型。
2. 顶部读取或输入主名。列表「新主名」默认留空，不自动填入。
3. 点击某行「填入主名」，仅更新这一行预览；可继续编辑主名和后缀。
4. 勾选后点击「执行勾选改名」，确认后才实际改名。未变化项跳过，冲突或受保护项显示原因。

后缀按原名最后一个下划线读取，如 `plant_1_n` → `plant_1` + `_n`；扩展名保持不变。内嵌网格等只读展示，不独立改名。筛选不会清除隐藏项勾选，执行包含全部已勾选项。

## 使用边界

- 移动和改名通过 Unity API 保持 GUID；代码、配置中的字符串路径需自行更新。
- 「未引用」以所选场景范围为准，不代表其他场景、独立资源或动态加载均未使用。清理前请核对范围。
- 删除使用系统回收站，恢复时同时恢复资源和 `.meta`；不支持 Unity Undo 恢复文件删除或资源改名。操作日志保存在工程的 `Library/ResourceOrganizerReports`。
- 依赖查询基于 Unity 已导入信息，无法识别任意代码字符串加载。内存分析是已加载对象估算，不等于显存或构建大小。
- 界面使用正常字重，标题按字号区分；前三个页签左右独立滚动。真实窗口缩放和鼠标交互仍需在具体工程中确认。

## 源码与验证

- `Assets/ResourceOrganizer/Editor`：完整编辑器源码及程序集定义。
- `Tests`：核心检查、Unity 引用编译与隔离工程集成验证源码。

本版通过 76 项核心/静态检查和 144 项 Unity 隔离工程集成检查。真实界面截图采集受阻，未完成视觉验收。

PowerShell 7 可运行核心检查：

```powershell
./Tests/Verify-Core.ps1
```

Unity 集成验证会创建、移动、改名和删除测试资源，**仅在带 `organizer-validation-project.marker` 标记的独立测试工程运行**，不要复制测试入口到工作工程执行。
